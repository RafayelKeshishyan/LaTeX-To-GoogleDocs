LaTeX for Google Docs

Extension settings

Keyboard shortcuts

These keys are built in and work inside any Google Doc. To change the browser-level shortcut that opens the editor, visit chrome://extensions/shortcuts.

Alt+=
Open the equation editor
Ctrl+Alt+M
Open the equation editor (fallback if Alt+= is taken)
Alt+Enter
Insert a standalone equation and return focus to Linear LaTeX
Alt+Shift+Enter
Start a new line below the cursor and insert the equation there
Up / Down arrow
Move a line and read any equation on it
F2
Edit the equation at the cursor, replacing it in place
Ctrl+Shift+R
Read the equation at the cursor aloud
Ctrl+Shift+Delete
Delete the equation at the cursor
Escape
Close the editor and return to the document

Speech output

How should the extension speak math?

Uses Chrome's speech engine. Does not move the cursor back to Linear LaTeX. This is the voice that worked before NVDA/JAWS were in the mix. Use it when no screen reader is running, or when Google Docs' own "application / document content" speech is too noisy.

The extension writes the complete natural-math sentence to a live region; your screen reader speaks it. After Alt+Enter, focus returns to Linear LaTeX so the next key cannot accidentally change document text. Google Docs may briefly say "application" or "document content" while accepting the insertion.

Accessibility

Turn this off if your screen reader already reads each character as you type it, which most do by default.
