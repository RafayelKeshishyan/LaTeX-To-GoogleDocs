# Tutorial 1 — Exponents

**Tutorial 1 — Exponents**

## Learning objective

Type exponents in LaTeX using the `^` character.

## Instructions

1. Press **Alt+=** to insert an equation.
2. Type the LaTeX below.
3. Press **Enter** to hear natural speech.
4. Press **F2** to edit if needed.

---

## Practice problems

### Problem 1

**LaTeX:** `x^2`

**Professional speech:** "x squared"

---

### Problem 2

**LaTeX:** `2^{10}`

**Professional speech:** "2 to the power of 10"

> Use curly braces `{ }` when the exponent is more than one character.

---

### Problem 3

**LaTeX:** `a^2 + b^2 = c^2`

**Professional speech:** "a squared plus b squared equals c squared"

---

### Problem 4

**LaTeX:** `y = 3x^2 + 2x + 1`

**Professional speech:** "y equals 3 x squared plus 2 x plus 1"

---

## TVI notes

- Teach `^` as "caret" or "hat" — students hear it on each keystroke in Linear mode.
- Curly braces for multi-digit exponents: `2^{10}` not `2^10` (which means `2^1` followed by `0`).
- Practice the same equations in the Math Pad before moving to Google Docs.

## Shortcut reminder

| Word | Google Docs |
