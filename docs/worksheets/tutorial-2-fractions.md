# Tutorial 2 — Fractions

**DigiMath Tutorial 2** | [Access Digi Math](https://accessuci.ics.uci.edu/digimath/)

## Learning objective

Type fractions in LaTeX using `\frac{numerator}{denominator}`.

## Instructions

1. Press **Alt+=** to insert an equation.
2. Type the LaTeX below.
3. Press **Enter** to hear natural speech.
4. Press **F2** to edit if needed.

---

## Practice problems

### Problem 1

**LaTeX:** `\frac{3}{4}`

**Professional speech:** "three fourths" or "3 over 4"

---

### Problem 2

**LaTeX:** `\frac{a}{b}`

**Professional speech:** "a over b"

---

### Problem 3

**LaTeX:** `\frac{x+1}{x-1}`

**Professional speech:** "the fraction with numerator x plus 1 and denominator x minus 1"

---

### Problem 4

**LaTeX:** `y = \frac{2}{3}x + \frac{1}{2}`

**Professional speech:** "y equals two thirds x plus one half"

---

## TVI notes

- `\frac` is spoken as "backslash frac" in Linear mode — students learn this on DigiMath first.
- Two arguments in curly braces: `\frac{top}{bottom}`.
- Nested fractions: `\frac{1}{\frac{2}{3}}` — save for advanced practice.
