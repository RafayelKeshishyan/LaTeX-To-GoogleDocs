# Tutorial 3 — Square Roots

**DigiMath Tutorial 3** | [Access Digi Math](https://accessuci.ics.uci.edu/digimath/)

## Learning objective

Type square roots in LaTeX using `\sqrt{expression}`.

This is the **acceptance test example** from [acceptance-test.md](../acceptance-test.md).

## Instructions

1. Press **Alt+=** to insert an equation.
2. Type the LaTeX below.
3. Press **Enter** to hear natural speech.
4. Press **F2** to edit if needed.

---

## Practice problems

### Problem 1 (acceptance test)

**LaTeX:** `y=\sqrt{x + 3}`

**Professional speech:** "y equals the square root of x plus 3"

---

### Problem 2

**LaTeX:** `\sqrt{16}`

**Professional speech:** "the square root of 16"

---

### Problem 3

**LaTeX:** `\sqrt{x^2 + y^2}`

**Professional speech:** "the square root of x squared plus y squared"

---

### Problem 4

**LaTeX:** `d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}`

**Professional speech:** Distance formula — natural speech describes nested operations.

---

## TVI notes

- `\sqrt` requires curly braces around the radicand: `\sqrt{x+3}`.
- This tutorial matches the Tina workflow from the Perkins-UCI webinar.
- After Enter, student should hear natural speech — NOT "image" or silence.
